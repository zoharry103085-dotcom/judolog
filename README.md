# JUDOLOG

유도 수련자가 운동 후 받은 코치 피드백을 **기술별로 정리**하고, 대회 전처럼 필요할 때 **기술 단위로 다시 꺼내 보는** 모바일 웹 UI 프로토타입입니다.

- 배포: https://judolog-1.vercel.app/
- 형태: 단일 HTML/CSS/JavaScript, 브라우저 `localStorage` 저장 (서버 없음) · 하이라이트 영상은 브라우저 `IndexedDB`에 이 기기에만 저장
- 기획·디자인: 조환서

## 파일
| 파일 | 설명 |
|---|---|
| `index.html` | 앱 본체 (v95 · 영상 여러 개 추가·조각 하나 삭제, 모바일 화면 점검 수정, 두 번 탭 확대 방지) |
| `404.html` | 없는 주소로 들어왔을 때 보이는 한국어 안내 페이지 |

## 디자인 규칙 요약 (v95)
- 어두운 배경(#0C0A09) + **주황 그라데이션 = 주요 행동**(주 버튼·현재 탭)
- **주황 테두리 = 누르면 무언가 열리는 보조 버튼**, 점선 = 아직 없는 것(추가할 항목·예시)
- 유도다움: 저장 때 柔 도장, 기록 횟수에 따른 띠 단계(흰띠 1~3 · 밤띠 4~9 · 검은띠 10~)
- 누르는 영역 최소 44px, 글자 12px 이상

# JUDOLOG

유도 수련자가 운동 후 받은 코치 피드백을 **기술별로 정리**하고, 대회 전처럼 필요할 때 **기술 단위로 다시 꺼내 보는** 모바일 웹 UI 프로토타입입니다.

- 배포: https://judolog-1.vercel.app/
- 형태: 단일 HTML/CSS/JavaScript, 브라우저 `localStorage` 저장 (서버 없음)
- 기획·디자인: 조환서

## 파일
| 파일 | 설명 |
|---|---|
| `index.html` | 앱 본체 (v63 · UI 5차 평가 반영, 들어올 때마다 입문부터) |
| `404.html` | 없는 주소로 들어왔을 때 보이는 한국어 안내 페이지 |

## 디자인 규칙 요약
- 색 12종: 먹색 배경, **빨강 = 행동**(주요 버튼·현재 탭), **금색 = 선택·성취**
- 글자 6단계: 12 / 14 / 16 / 20 / 24 / 32px (단계 제목 20px)
- 여백 4의 배수, 모서리 4px · 8px · 원형, 누르는 영역 최소 44px, 주요·보조 버튼 48px
- 점선 = 아직 없는 것(추가할 항목·예시)
